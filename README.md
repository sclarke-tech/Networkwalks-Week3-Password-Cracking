## Project Overview

During Week 3 of the Networkwalks Cybersecurity Internship, I completed hands-on password-cracking exercises using John the Ripper, Johnny GUI, Kali Linux, and Networkwalks Academy's browser-based security tools.

These exercises focused on password hash extraction, dictionary attacks, password recovery, and understanding the security risks associated with weak passwords.

All activities were conducted in an authorized training environment.

## Project 1: John the Ripper – Kali Linux

- Practiced password-cracking techniques using Kali Linux.
- Worked with John the Ripper in a Linux terminal.
- Documented the commands, procedures, and results in a technical report.

**Documentation:** `Networkwalks_Week3_JTR_Kali_Linux_Report.pdf`

## Project 2: John the Ripper – Johnny GUI (Windows)

- Configured John the Ripper Jumbo and Johnny GUI.
- Extracted a password hash from an encrypted training PDF using `pdf2john.pl`.
- Performed a dictionary-based password attack.
- Successfully recovered the password `good-luck`.
- Opened the protected training PDF and captured the flag.

## Project 3: Password Cracking with Networkwalks Tools (PM2)

- Used the Networkwalks Hash Calculator to extract an encrypted PDF hash.
